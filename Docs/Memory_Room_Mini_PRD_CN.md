# VR 记忆实验室 — Mini PRD（中文版）

**状态：** 方案草稿（2026-10-08）  
**范围：** 只描述我的记忆实验 room。它在同一空间中切换两种环境模式。

## 1. 核心想法

参与者分别在「嘈杂办公室」和「自然放松环境」中完成规则相同的 VR 卡片配对任务。房间会记录任务表现，并询问参与者觉得刚才有多费脑力。重点是比较**环境改变后，完成表现和主观认知负担是否变化**。

## 2. 研究目标

**研究问题：** 在同样的记忆任务下，办公室与自然环境会不会影响完成时间、错误次数，以及参与者报告的脑力负担？

**初步预期：** 自然环境可能让参与者感觉更轻松；客观记忆表现是否变化保持开放，不预设一定有差异。这个课程原型用于展示实验设计，不把少量试用结果当作心理学结论。

## 3. 论文灵感

Orti 等人（2026）的论文 [*Environmental Modulation of Perceived Cognitive Workload During a Memory Task: Evidence from Immersive Virtual Reality*](https://doi.org/10.3390/jintelligence14080158) 让参与者在 VR 办公室和城市公园中做卡片配对，比较操作次数、用时和主观认知负担。论文报告：两种环境的客观表现没有显著差异，但自然环境中的主观认知负担较低。

**我借用的方法：** 同一个记忆任务放进两种环境，同时观察行为数据与主观感受。**我的改动：** 使用更轻量的两种房间氛围、简短的单题负担评分，并加入课程要求的倒计时和可交互控制。

## 4. 参与者流程

1. 阅读简短说明，开始第一轮环境。
2. 用 VR 控制器射线翻开 12 张卡片，找出 6 对相同图案；倒计时上限暂定 **180 秒**。
3. 完成或超时后，看到结果，并回答「刚才的任务有多费脑力？」（1–5 分）。
4. 卡片重置、位置重新排列，切换到另一种环境，重复相同任务。
5. 显示两轮结果；可按 Reset 从头开始。

为减少练习效应，试用时让部分参与者先做办公室，另一部分先做自然环境。两轮保持卡片数量、规则、桌面位置、操作方式和时间上限一致。

## 5. 两种环境

| 条件 | 视觉与灯光 | 3D 音效 |
| --- | --- | --- |
| 办公室 | 文件、屏幕、冷色灯光，略显忙碌 | 键盘、电话和轻度办公背景声 |
| 自然环境 | 植物、绿色景观、柔和灯光 | 鸟鸣、流水和轻度自然背景声 |

环境通过运行时开关切换，卡片任务本身不变。音量会保持舒适，避免噪声过强影响 VR 体验。

## 6. 要做出的功能与数据

- **交互：** 控制器二维轴平滑移动、射线翻牌、开始与 Reset 按钮；匹配成功的卡片可落入收集盒，展示物理效果。
- **反馈：** 世界空间 Canvas、3D TextMeshPro 说明、倒计时、配对进度和结果面板。
- **环境：** 运行时切换装饰、灯光与空间音效。
- **记录：** 每轮环境、完成/超时、用时、翻牌或配对次数、错误配对次数、1–5 分脑力负担评分。先在界面显示，是否导出 CSV 视开发进度决定。

## 7. 实施顺序与完成标准

| 目标时间 | 里程碑 |
| --- | --- |
| 10/8–11 | 灰盒 room：VR 移动、翻牌、配对、倒计时和 Reset 可运行 |
| 10/12–16 | 完成两套环境、灯光与 3D 音效；加入结果和评分 |
| 10/17–20 | 用 Meta Quest 实测并修正文字大小、交互距离、舒适度和错误 |
| 10/21 | 冻结可演示版本，准备该 room 的说明和录屏 |

**完成标准：** 参与者无需开发者协助，能连续完成两轮、看见结果，并用 Reset 再做一遍；切换环境时卡片、计时和评分状态正确恢复。第三种环境暂不列入基本范围。
