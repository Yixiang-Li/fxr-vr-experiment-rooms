# 我的 Memory Room — 简版 PRD

**交付方式：** 电脑键盘／鼠标，Unity 2022.3.62f3。更新：2026-10-14。范围只包括我的房间。

## 概念与研究问题

参与者分别在办公室和自然主题的 3D 场景中做同一个记忆配对任务，比较完成情况、时间、错误次数和主观心理负担。

研究问题：**电脑端 3D 虚拟环境的氛围，是否影响记忆表现与主观 mental effort？** 自然环境可能感觉更轻松，但客观表现是否改变是开放问题。小规模试用只检验可用性，不能证明心理效应；桌面结果不能当成头显 VR 结果。

## 论文灵感

Orti et al.（2026），[Environmental Modulation of Perceived Cognitive Workload During a Memory Task: Evidence from Immersive Virtual Reality](https://doi.org/10.3390/jintelligence14080158)。灵感是用相同的配对任务比较不同环境，同时观察表现和主观负担。

本项目改成屏幕与鼠标操作，只用一题探索性的 1–5 负担评分，不复现论文的沉浸设备或量表。

## 参与者流程

1. 预览办公室／自然环境，选择先后顺序和声音；可先拖动橙色方块练习。
2. 点击 Start 或按空格，自动回到两轮相同的任务视角。
3. 左键翻两张牌，180 秒内寻找 12 张卡片中的 6 对。
4. 完成／超时后评心理负担 1–5；进入另一种环境，卡片重新洗牌。
5. 两次评分后统一显示结果，并自动保存 CSV；点击 CSV FOLDER 打开目录。

F 回到任务视角；任务外用 WASD／右键探索，G 切滑行／飞行，飞行时 Q／E 下／上。正式两轮及评分时锁定移动与练习拖动。Esc 暂停；失去窗口焦点和 Reset 确认也暂停计时。中断轮次有标记，比较时建议重做。

## 环境与实验控制

- 办公室：免费桌椅、台灯、时钟、摄影材质、城市窗景；真实办公／键盘录音及冷色背景补光。
- 自然环境：免费植物、绿植／森林窗景；真实鸟鸣／溪流录音及绿暖色背景补光。
- 两轮保持卡片数量、规则、任务灯、牌面、相机、布局与时间限制一致。使用同一电脑、同一副耳机和相同系统音量。
- 不同参与者交替先做办公室／自然环境；洗牌降低记住上轮位置的影响，但不消除所有练习效应。

## 实现与数据

我的工作源仍是 MemoryDev；现有房间 Prefab 整合在 MainScene，不重建房间几何。包含 Canvas＋3D TextMeshPro、倒计时、进度、评分、帮助、暂停、重置和新会话确认。鼠标射线选牌，独立方块演示远距拖动；配对成功卡片落入物理收集盒。装饰、背景灯光和空间细节音随环境切换。

CSV 记录环境、完成／超时、时间、配对数、翻牌数、尝试／错误、心理负担、输入方式、版本、声音和中断；不收集参与者姓名。
