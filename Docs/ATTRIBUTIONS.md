- Unity 3D URP template settings: Unity editor 6000.3.24f1, template 17.0.14.
- XR Interaction Toolkit **3.3.2 Starter Assets** and **XR Interaction Simulator**: Unity Technologies. Original sample metadata is retained. These assets are governed by the package's Unity Companion License; see the retained [package license notice](ThirdParty/XRInteractionToolkit-LICENSE.md) and the installed package license.
- TextMesh Pro Essential Resources / LiberationSans SDF: bundled Unity UI package resources. Included notices and font licenses are retained in `Assets/TextMesh Pro/Fonts/`.
- Memory-room geometry, symbol meshes, task code, and synthetic office/nature placeholder audio: created for this project with AI assistance. No external furniture models, commercial asset packs, or downloaded ambient recordings are currently included.

Research inspiration: Orti et al. (2026), *Environmental Modulation of Perceived Cognitive Workload During a Memory Task: Evidence from Immersive Virtual Reality*, Journal of Intelligence 14(8), 158. https://doi.org/10.3390/jintelligence14080158

The prototype does not claim to reproduce the study or demonstrate an effect of nature on memory. Its one-item effort rating, time limit, and minimal room are project adaptations.
