# Teammate C

Open `Scenes/RoomCDev.unity` and press Play. Edit ordinary scene objects under the `RoomC` root; keep scripts, materials, models, and audio in this folder. The starter room contains only a floor and walls, with a ready testing player outside the room root.

When ready, the integration owner packages `RoomC` as a prefab and places it in MainScene. Keep the testing player, EventSystem, interaction manager, and shared daylight outside the room prefab. Keep the development scene; only MainScene is enabled for final builds. See `Docs/TEAM_SETUP_EN.md`.
